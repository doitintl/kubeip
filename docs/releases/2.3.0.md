# Agent 2.3.0 release candidate

## Changes

- Support STANDARD-tier reserved IPv4 addresses on GCP (#155), while preserving the project default tier when restoring an ephemeral IPv4 address.
- Allow AWS nodes without an EKS managed-node-group label, including self-managed and Karpenter nodes (#152).
- Return an existing AWS EIP on restart and verify the primary public address before treating an existing assignment as ready. GCP checks the managed interface for IPv4 and IPv6.
- Sort GCP addresses locally after pagination so ordering works with filters (#132). Supported fields are name and creationTimestamp, with optional asc or desc.
- Add WAIT_FOR_NODE_ADDRESS / --wait-for-node-address, defaulting to true (#175). Egress-only workloads can opt out of the Node-status wait. GCP operation-wait failures no longer count as successful assignment.
- Stop sleeping after the final unsuccessful assignment or readiness check.
- Use startup-taint examples in the documentation (#160).
- Embed the release tag in the agent version string. Chart tags no longer trigger agent image publication.
- Update the build toolchain to Go 1.26.9 and the HTTP/2 dependency to golang.org/x/net v0.60.0, with required companion dependency updates.

## Compatibility

Existing deployments keep the Node-status wait unless explicitly disabled. Source builds now require Go 1.26 or later; the release toolchain is Go 1.26.9. GCP order expressions outside the documented fields and directions return an error before address replacement.

## Chart 0.2.0

The chart now honors image.tag and exposes WAIT_FOR_NODE_ADDRESS. A separate workflow validates, packages and publishes chart-v<VERSION> tags to GHCR. See [chart release instructions](../../chart/README.md). Publish the agent before a chart installation uses its new wait option.

## Release gates

- Run the Go tests with the release toolchain, the race detector, golangci-lint and govulncheck.
- Validate both workflows and Helm rendering/package output.
- Build the agent container and verify its version output and non-root user.
- Validate live GCP STANDARD/PREMIUM assignment and ephemeral restoration, AWS restart behavior, and taint waiting enabled/disabled in disposable nodes. Include a node with multiple interfaces.
- Merge the reviewed changes and require successful CI builds for linux/amd64 and linux/arm64 before tagging 2.3.0. PR #170 is already included in the branch history.
- Publish the agent release, verify image pulls, then publish chart-v0.2.0. Make the GHCR package public and register it with Artifact Hub after its first publication.

Larger design-dependent issues (#126, #147, #150, #156 and #166) and the unreproduced label-loss report (#154) remain open.
